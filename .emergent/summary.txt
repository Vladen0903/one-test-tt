<product_requirements>
The primary goal is to develop a comprehensive project management web service, TT-Manager, evolving from a basic Trello-like application.
Key features include:
- **Project Management Core:** Kanban boards (drag-and-drop), backlog with sprints, Gantt charts, release calendar, epics/subtasks.
- **Task Management:** Detailed task viewing/editing modal, task deletion, assignee assignment, labels (tags) with colors, comments, attachments, checklists, dependencies, start/end dates.
- **User & Access Control:** User registration/authorization (email/password, OAuth), teams and projects (private projects), granular roles/permissions (Owner, Admin, Member, Viewer, Director), adding/removing project users, assigning user-specific tasks, user profiles (name, photo, description, contact info).
- **UI/UX:** UI customization (themes, branding), improved navigation, multilingual support (English, Russian, Ukrainian - user-specific), separate 'Boards' section, 'Team' renamed to 'Company' in sidebar with enhanced settings.
- **Backend/Database:** Next.js API routes, SQLite (local), PostgreSQL (production), Prisma ORM, robust database schema.
- **Specific Updates:** Calendar showing all backlog tasks, releases, and user-assigned events; board settings for column customization; release management linked to boards/tasks; backlog editing/sprint linking; ability to work without created projects; removing Gantt charts for future updates; centralized profile and settings in header.
</product_requirements>
