## 🎯 Как использовать

### Полный flow:

1. **Войти в систему** (`http://localhost:3000`)
2. **Dashboard** - создать команду
3. **Dashboard** - создать проект в команде
4. **Кликнуть на проект** → переход на `/project/[id]`
5. **Создать доску** (Board)
6. **Кликнуть на доску** → переход на `/board/[id]`
7. **Создать задачи** в колонках (+ Add Task)
8. **Работать с задачами** - менять приоритеты, описания

### Навигация:

```
Dashboard
  └─ Projects
       └─ Project Detail
            └─ Boards
                 └─ Board (Kanban)
                      └─ Tasks
```

## 🔄 Обновление проекта

Если вы уже скачали проект:

```bash
# Синхронизировать изменения
rsync -avz --progress --exclude='node_modules' --exclude='.next' \
  user@server:/app/frontend/ ./tt-manager/

# Перезапустить
cd tt-manager
yarn dev
```

Или скачать новый архив:

```bash
scp user@server:/app/tt-manager-complete.tar.gz .
tar -xzf tt-manager-complete.tar.gz
cd frontend
yarn install && yarn prisma:push && yarn dev
```

## 📚 API документация

### Tasks API

```typescript
// Получить задачи
GET /api/tasks?projectId=xxx&columnId=yyy
Headers: Authorization: Bearer <token>

// Создать задачу
POST /api/tasks
Body: {
  projectId: string
  boardId?: string
  columnId?: string
  title: string
  description?: string
  priority?: 'lowest' | 'low' | 'medium' | 'high' | 'critical'
  dueDate?: string
}

// Обновить задачу
PATCH /api/tasks/:id
Body: {
  title?: string
  description?: string
  columnId?: string
  priority?: string
  status?: string
  assigneeId?: string
  dueDate?: string
}

// Удалить задачу
DELETE /api/tasks/:id
```
